# readhtml

Read color html values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/readhtml/

## Install / run

```bash
git clone https://github.com/theworker02/readhtml.git
cd readhtml
node src/cli.js
node --test
```
